# React-Project
##  Notes App

### A simple Notes App built using React + Vite.

### Features
Add notes  
Delete notes  
Simple and responsive UI  
### Tech Stack
React  
Vite  
JavaScript  
CSS  


### Run Locally

npm install  
npm run dev  


### How To Create npm vite file

-npm create vite  
-give project name  
-Select Framework as React  
-Select Variant as JavaScript  
-Select linter as Eslint  
-Start with npm
